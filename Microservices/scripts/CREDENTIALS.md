## To Re-seed on a New Server

```bash
# Clone repo, then:
cd Microservices
docker compose up -d postgres-app postgres-delivery postgres-driver rabbitmq minio
# Wait ~30s for containers to be healthy, then:
bash scripts/reset-and-seed.sh
# Then bring up the rest:
docker compose up -d
```
