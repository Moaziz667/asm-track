\chapter*{Résumé}
\addcontentsline{toc}{chapter}{Résumé}

Ce rapport présente la conception et le développement d'\textbf{ASM Track}, une plateforme SaaS multi-tenant de gestion et de suivi des livraisons en temps réel. La solution repose sur une architecture microservices composée de cinq services indépendants, un serveur d'authentification OAuth2 personnalisé, et une API Gateway. Elle intègre une application web d'administration (Next.js), un panneau super-administrateur (React/Vite), et une application mobile Flutter pour les chauffeurs.

Les fonctionnalités clés incluent : un constructeur de tournées avec routage OSRM, une intégration ERP agnostique (Odoo, Dux) via le pattern Ports \& Adapters, le suivi en temps réel via WebSocket STOMP, la capture de preuves de livraison avec stockage MinIO, et un moteur de reporting PDF multi-tenant.

\textbf{Mots-clés :} microservices, SaaS, multi-tenancy, livraison, temps réel, Flutter, Spring Boot, ERP, OAuth2.

\chapter*{Abstract}
\addcontentsline{toc}{chapter}{Abstract}

This report presents the design and development of \textbf{ASM Track}, a multi-tenant SaaS platform for real-time delivery management and tracking. The solution is built on a microservices architecture comprising five independent services, a custom OAuth2 authentication server, and an API Gateway. It integrates a Next.js admin web application, a React/Vite super-admin panel, and a Flutter mobile application for drivers.

Key features include: a route builder with OSRM routing, an ERP-agnostic integration (Odoo, Dux) using the Ports \& Adapters pattern, real-time tracking via WebSocket STOMP, proof-of-delivery capture with MinIO storage, and a multi-tenant PDF reporting engine.

\textbf{Keywords:} microservices, SaaS, multi-tenancy, delivery, real-time, Flutter, Spring Boot, ERP, OAuth2.
