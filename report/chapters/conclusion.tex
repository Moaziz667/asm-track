\section*{Bilan}

Ce projet nous a permis de concevoir et de développer ASM Track, une plateforme SaaS complète de gestion des livraisons. Les principaux acquis sont :

\begin{itemize}
  \item La maîtrise de l'architecture microservices avec Spring Boot et Docker
  \item La conception d'un serveur d'authentification OAuth2 personnalisé
  \item L'implémentation du pattern Ports \& Adapters pour une intégration ERP agnostique
  \item Le développement d'une application mobile Flutter avec mode hors-ligne
  \item La mise en place d'une architecture SaaS multi-tenant
\end{itemize}

\section*{Perspectives}

Plusieurs axes d'amélioration peuvent être envisagés :

\begin{itemize}
  \item \textbf{Optimisation des tournées} : intégration d'algorithmes VRP (Vehicle Routing Problem) pour l'optimisation automatique des itinéraires
  \item \textbf{Intelligence artificielle} : prédiction des délais de livraison basée sur l'historique
  \item \textbf{Expansion ERP} : ajout d'adaptateurs pour SAP, Microsoft Dynamics
  \item \textbf{Application client} : portail web de suivi pour les destinataires finaux
  \item \textbf{Analytics avancés} : tableaux de bord temps réel avec agrégation de métriques
\end{itemize}
